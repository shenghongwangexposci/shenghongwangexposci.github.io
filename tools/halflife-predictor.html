Whole-body elimination half-life

Estimates a chemical's elimination half-life (t½) with the classical one-compartment relationship t½ = ln(2)·Vd/CLtotal, built from the same partitioning and IVIVE machinery as the Fbio tool — accounting for hepatic metabolism, systemic gut-wall metabolism, and renal excretion. Built on the mechanistic model in Wang, Zhang, Saunders, Li & Li, Environmental Science & Technology 58 (2024) 14135–14145.

Method

Uses the classical one-compartment relationship t½ = ln(2)·Vd/CLtotal — the same relationship EPA's httk package uses in its own calc_half_life() — built from the same partitioning and IVIVE machinery as the Fbio tool. Vd sums each tissue's volume weighted by its plasma-partition coefficient; CLtotal combines hepatic and gut-wall clearance (each blood-flow-limited via the well-stirred/venous-equilibrium model, CLorgan = Qorgan·Clint,organ / (Qorgan + Clint,organ)) with renal clearance. This is a closed-form calculation, not a simulation.

Note: half-life is a derived extension built on the paper's validated model, not a value the paper itself reports or validates directly. Treat it as screening-level.

Note: for hepatocyte-assay inputs, fu,hep defaults to a mechanistic, composition-based two-phase (cell + medium) partition model built on this tool's own Kwater framework, using measured HepG2 cell composition (Fischer et al. 2017) and primary-hepatocyte cell volume (Bellwon et al. 2015 via Lin et al. 2025) — rather than the Kilford et al. (2008) empirical regression, which remains available via the fu,hep method toggle for comparison. This does not affect the microsome branch or either example above.

Note: Papp,Caco-2 only affects t½ through the renal-reabsorption term above. If a chemical has no measured Caco-2 permeability, check “no Caco-2 data” to assume 0% reabsorption (fully filtered, no tubular reabsorption) instead of guessing a value.

Note: gut-wall metabolism is off by default — most chemicals have little to no first-pass metabolism in the intestinal wall itself (as opposed to the liver), and it typically requires its own in vitro measurement that most chemicals won't have. Turn it on only if you have a Clint,wall value for this chemical.

Built on the PBTK model from Wang, S., Zhang, Z., Saunders, L. J., Li, D., Li, L. (2024). Understanding the impacts of presystemic metabolism on the human oral bioavailability of chemicals. doi.org/10.1021/acs.est.4c03344 — the half-life calculation itself is a derived extension, not a number from the paper.
