Numerical ODE solver

Enter any system of first-order ordinary differential equations — one line per equation, in the form dY/dt = expression — and integrate it numerically with Euler, Heun (RK2), or classical RK4. Works for any coupled system: compartmental PBTK models, epidemic models, predator–prey dynamics, mechanical oscillators, and more.

Method

Euler — yⁿ⁺¹ = yⁿ + Δt·f(tⁿ, yⁿ). 1st-order accurate (global error ∝ Δt); cheapest per step but can drift or go unstable, especially on oscillatory or stiff systems.

Heun / RK2 — averages the Euler slope at the start and predicted end of each step. 2nd-order accurate (error ∝ Δt²).

Classical RK4 — blends four slope evaluations per step (start, two midpoint estimates, end). 4th-order accurate (error ∝ Δt⁴) and a good default for smooth, non-stiff systems.

All three are fixed-step, explicit methods — there is no adaptive step-size control or implicit solver here, so a very stiff system may need an impractically small Δt to stay stable. This is a screening-level tool, not a substitute for a dedicated numerical package (SciPy, MATLAB, etc.) on production work.
